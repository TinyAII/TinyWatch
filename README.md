# TinyWatch

**网页监控面板 —— 实时看玩家在哪、服务器累不累、刚才谁做了什么。**

单文件插件，零依赖，内置 HTTP 服务，打开浏览器就能看。

![Version](https://img.shields.io/badge/version-1.1.1-blue) ![License](https://img.shields.io/badge/license-MIT-green) ![API](https://img.shields.io/badge/API-1.13%2B-orange)

---

## 它跟别的监控插件有什么不同

市面上有两类工具：

| | 问题 |
|---|---|
| **Plan** | 功能极全，但 jar 装完 20+ MB、依赖 H2/SQLite、启动慢、全英文，而且数据是**定时聚合**的 —— 你看到的是「过去 30 分钟」 |
| **CoreProtect** | 方块日志做到了极致，但它是**事后回滚**工具，没有实时面板，也没有服务器负载 |

TinyWatch 只做一件事：**现在正在发生什么**。

- 玩家现在在哪个坐标、血多少、饿不饿、卡不卡
- 服务器现在是 20 TPS 还是 12 TPS，内存还剩多少
- 刚才那五分钟里，谁挖了什么、开了谁的箱子、敲了什么命令

**它不替代 Plan，也不替代 CoreProtect。** 需要长期统计看 Plan，需要回滚存档看 CoreProtect，需要「马上是怎么回事」看这个。

## 功能

### 实时状态

- 在线玩家表：坐标、所在区块、血量、饥饿、等级、模式、延迟、本次在线时长
- 点某个玩家 → 右侧抽屉看详情 + 他最近的操作记录
- TPS / MSPT / 内存 / 实体数 / 已加载区块，三条曲线实时滚动（最近 5 分钟）

### 操作日志

「日志」页只放**游戏里真正发生的事**，聊天和系统消息在另一个页签，不混在一起。

默认记录这些类型：

| 类型 | 内容 |
|---|---|
| 破坏 | 方块名 + 精确坐标 |
| 放置 | 方块名 + 精确坐标 |
| 容器 | 打开了什么容器（箱子 / 木桶 / 熔炉…），以及从里面取放了什么 |
| 命令 | 完整命令内容 |
| 死亡 | 死亡或被谁击杀 |
| 进出服 | 上下线 |
| 管理 | 网页上执行过的每一个操作 |

- 按玩家、按类型、按关键词筛选
- 实时推送到页面，不用刷新
- 保留最近 5000 条（可配），超了挤掉最旧的
- 可以导出 CSV 留证

### 世界消息（聊天框）

玩家说的、服务器广播的、插件报错的，都在一个页签里，按类筛选：

| 筛选 | 收什么 |
|---|---|
| 玩家 | 玩家发言（真实文本，带说话人） |
| 系统 | 服务器公告、广播、进服 / 退服、死亡播报 |
| 插件 | 插件发出的 WARN / ERROR |
| 指令 | 玩家执行的命令 |

- 消息来自两路：聊天事件（含 Paper 的 `AsyncChatEvent`，用反射挂）+ 服务端日志
- **插件自己的 INFO 日志不收** —— 那是控制台噪声，玩家在聊天框里看不到
- 没人在线时不记录，避免开机自检日志刷屏
- 配了关键词（广告、拉群之类）会标红成一条「警报」，可设置自动禁言

### 世界管理

主世界 / 下界 / 末地分别设置：

- **时间**：白天、正午、夜晚、午夜、自定义 tick
- **天气**：放晴、下雨、雷雨 + 持续分钟
- **难度**：和平 / 简单 / 普通 / 困难
- **游戏规则**：时间流动、刷怪、死亡不掉落、生物破坏、PVP、TNT 爆炸、摔落伤害、随机刻速度…共 14 条
- **出生点 / 世界边界**（直径、中心）
- **维护**：保存世界、清掉落物、清生物

游戏规则名各版本叫法不同（26.x 是 `advance_time`，老版本是 `doDaylightCycle`；26.x 是 `natural_health_regeneration`，老版本是 `naturalRegeneration`）。插件按候选名依次尝试，不会因为版本差异失效。

### 网页操作

22 项，按组开关：

| 组 | 内容 |
|---|---|
| 状态 | 治疗、旁观、游戏模式、清除效果、给药水效果、经验等级、飞行、隐身 |
| 物品 | 给物品、修复耐久、拿走某格（点背包格子）、清掉落物、清空背包 |
| 位置 | 传送坐标、传到玩家、送回出生点、冻结、坐标记录与拉回 |
| 沟通 | 发消息、屏幕标题、动作栏、音效 |
| 处罚 | 踢出、封禁、禁言、白名单、OP |
| 经济 | 查余额、给 / 扣点券（需要 Vault） |

- **可撤销**：游戏模式、传送、清空背包、拿走物品、OP、冻结、禁言、白名单增删 —— 执行后 5 分钟内点「撤销」，会反着做一遍
- 不可逆的（清掉实体、封禁）弹二次确认
- 每个操作都写进操作日志，类型「管理」

### 处罚记录

禁言和封禁落盘到 `plugins/TinyWatch/punishments.yml`：

- 记谁、什么类型、原因、起止时间
- 服务器重启后禁言仍然生效
- 系统页能看到列表，逐条解除

### 黑名单

服务器原版封禁（`banned-players.json`，用 `/ban` 或别的插件封的都算）和网页封禁**合并成一张表**，标注来源，一键解除。

只看一边都会漏人，所以两边都要读。

### 插件清单

列出所有已装插件和它们的「占用」：

| 指标 | 怎么来的 |
|---|---|
| 事件监听器 | 遍历 `HandlerList` 反查注册者 |
| 命令数 | 读 jar 里的 `plugin.yml` |
| 待执行任务 | 调度器里 owner 是这个插件的任务 |
| jar 大小 | 从保护域拿到真实文件路径 |

**不显示内存**：Bukkit 没有 per-plugin 内存 API，编一个数字只会误导判断。监听器数量最能说明「这个插件吃不吃 tick」—— 每来一个事件它都要调一次。

### 预警 / 轨迹 / 版本

- **预警横幅**：TPS 连续低于阈值、内存超 85%、实体数爆、有玩家一分钟破坏上百块 —— 顶部挂一条红/黄提示，恢复正常自动消失
- **玩家轨迹**：最近 5 分钟的走位画成俯视折线（起点绿、终点红），追查「谁拆的房子」比翻方块日志快得多
- **版本卡片**：当前版本 / 最新版本 / 更新说明 / 上次检查时间，可以手动「立即检查」

### 计划任务

按 `at: "04:00"`（每天）或 `every: "30m"`（间隔）定时执行：

- `broadcast` 广播一句话
- `save` 保存所有世界
- `clear-items` 清理全服掉落物
- `restart` 关服（谨慎配置）

### 导出

日志和聊天都能导 CSV：带 UTF-8 BOM（Excel 直接打开不乱码），以 `=` `+` `-` `@` 开头的内容会加前缀，防止被当成公式执行。

### 技术特点

- **零依赖**：不用 Vault、不用 PlaceholderAPI、不引任何第三方库
- **单 jar**：网页就打包在插件里，不用另外部署静态站点
- **纯 Bukkit API**：不用 NMS、不用反射改内部（只有取延迟、挂 Paper 现代聊天事件用了反射，都带降级）
- **默认保守**：网页操作按组开关，破坏性的（清实体、封禁、OP）单独控制；所有操作回主线程执行并写审计日志
- **安全**：密码只存 PBKDF2 哈希、登录失败 5 次按 IP 锁 5 分钟、只读分享链接、CSP

## 安装

1. 把 `tinywatch-1.1.1.jar` 放进 `plugins/`
2. 重启服务器
3. **控制台会打印一个自动生成的登录密码**，只显示这一次，抄下来：

```
=====================================================
 首次启动，已自动生成一个登录密码（下面只显示这一次）：

     atHsC33HpgsgpCAS

 服务器上只存了它的哈希，配置文件里看不到明文。
 忘了就用 /watch 新密码 重新生成一个。
=====================================================
```

4. 浏览器打开 `http://服务器IP:8123/`，输入密码

> 默认监听 `0.0.0.0`，装完就能从外面打开。
> 但这意味着面板直接暴露在公网，只有密码挡着 —— 长期用请往下看「怎么从外网访问」。

## 怎么从外网访问

面板上能看到所有玩家的坐标和操作记录。**直接把它暴露在公网上，等于在服务器上装了一个只靠密码守着的摄像头。**

默认配置（`host: 0.0.0.0`）是「能用」的取舍：装完不至于一头雾水。但只要这台机器有公网 IP，全世界的扫描器都能访问到登录页。有条件就换成下面方式一或方式二。

### 方式一：SSH 隧道（最安全，推荐）

在自己电脑上执行：

```bash
ssh -L 8123:127.0.0.1:8123 root@你的服务器IP
```

保持这个窗口开着，浏览器打开 `http://localhost:8123` 即可。

**服务器上一个端口都不用开，也不用配 nginx 和证书。**

### 方式二：nginx 反代 + 域名

```nginx
server {
    listen 443 ssl http2;
    server_name watch.example.com;

    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:8123;
        proxy_http_version 1.1;

        # SSE 必须关掉缓冲，否则事件会卡在 nginx 里不下来
        proxy_buffering off;
        proxy_set_header X-Accel-Buffering no;

        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # SSE 是长连接，读超时不能太短
        proxy_read_timeout 3600s;
    }
}
```

**两个关键点**，漏了会出问题：

1. `proxy_buffering off` + `X-Accel-Buffering: no`
   nginx 默认会把响应缓冲起来，SSE 的实时推送会一直卡着不出来，页面看起来「连上了但不动」。
   （插件自己也会发 `X-Accel-Buffering: no` 头，双保险。）

2. `proxy_read_timeout` 要放大
   默认 60 秒，SSE 连接会被掐断重连。插件每 5 秒发一次心跳，一般够用，但放大更稳。

### 方式三：直接监听 0.0.0.0（默认，但要加防护）

```yaml
web:
  host: "0.0.0.0"
```

这是默认值，装完就能用。代价是登录页对全网可见，只有密码挡着。

真要用这个方式，至少做一件事：**在防火墙/安全组里限制来源 IP**。

```bash
# 只允许你自己的 IP 访问 8123
ufw allow from 1.2.3.4 to any port 8123 proto tcp
ufw deny 8123/tcp
```

另外注意 **HTTP 是明文的**：密码和会话 token 在网络上是裸奔的，任何中间节点都能截。这也是为什么有条件就上方式一或方式二。

## 指令

主命令 `/watch`，别名 `/tw`、`/监控`。**只有 op 能用。**

| 英文 | 中文 | 作用 |
|---|---|---|
| `/watch status` | `/watch 状态` | 看面板地址、连接数、日志条数 |
| `/watch password` | `/watch 密码` | 查看当前登录密码 |
| `/watch newpassword` | `/watch 新密码` | 重置密码（所有已登录页面会掉线） |
| `/watch clear` | `/watch 清空` | 清空内存里的操作日志 |
| `/watch reload` | `/watch 重载` | 重载配置 |

Tab 补全中英文都支持。

## 配置

改完执行 `/watch 重载` 生效，不用重启服务器。

**升级不会丢配置**：插件启动时会把 `config.yml` 和新版模板比对，缺的项自动补上，
你改过的值原样保留，注释也会留着。动手前先备份成 `config.yml.bak`，
补完还会再解析一遍确认没写坏 —— 任何一步不对就放弃，原文件一个字节不动。

```yaml
web:
  enabled: true
  host: "0.0.0.0"          # 默认对外；只想本机访问或挂反代时改成 127.0.0.1
  port: 8123
  password: ""             # 留空 = 首次启动自动生成，只存哈希
  password-hash: ""        # 自动生成，别手改
  trust-proxy: false       # 挂反代时改成 true，才会读 X-Forwarded-For
  session-hours: 12        # 登录有效期
  show-ip: false           # 是否在面板上显示玩家 IP（默认关，属于隐私）

monitor:
  sample-interval-ticks: 20   # 采样间隔，20 tick = 1 秒
  history-size: 300           # 曲线保留多少个点（300 × 1 秒 = 5 分钟）
  slow-stat-every-samples: 5  # 实体数/区块数每 5 次采样才统计一次（遍历全世界比较贵）

events:
  enabled: true
  buffer-size: 5000           # 内存里留多少条日志（约 600 KB）
  record:
    block-break: true
    block-place: true
    container: true
    container-click: false    # 容器内点击，默认关（事件量太大）
    command: true
    death: true
    join-quit: true
  ignore-worlds: []           # 排除刷怪塔、自动农场等高频繁区域
  ignore-commands:            # ⚠️ 登录类命令必须留在这里，见下
    - login
    - register
    - l
    - reg
    - changepassword
    - cp
    - passwd
    - password
```

### ⚠️ 关于 `ignore-commands`（很重要）

**登录插件的命令参数里是明文密码**，比如 `/login MyPassword123`。

如果记进日志，等于**把全服玩家的密码明文写在网页上**，任何能打开面板的人都能看到。

插件默认已经屏蔽了常见登录插件的命令。**如果你用的是别的登录插件（AuthMe、LibsDisguises 认证之类），请把它注册的命令加进这个列表。**

### 修改后生效

改完配置执行 `/watch 重载` 即可，不用重启服务器。

## 兼容性

| 项 | 值 |
|---|---|
| 服务端 | Spigot / Paper / Purpur |
| 版本 | **1.13 ~ 26.x** |
| Java | **8+** |
| 前置 | **无** |
| NMS | 零（纯 Bukkit API） |

### 不同版本上的差异（都做了降级，不会崩）

| 功能 | 拿不到时的表现 |
|---|---|
| MSPT | Spigot / 1.13 没有 `getAverageTickTime`，面板显示「服务端未提供」，**不会编一个假数字** |
| 玩家延迟 | 1.16.4 以下靠反射读实体字段；读不到显示「—」 |
| 新版本容器（木桶/高炉/烟熏炉…） | 用字符串匹配识别，1.13 上只是不会出现这些类型 |

## 为什么日志不落盘

落盘要处理磁盘 IO、文件轮转、并发写、断点恢复。这是日志审计插件（CoreProtect 那类）的活，它们已经做得很好。

TinyWatch 的定位是「现在正在发生什么」。重启清空是可以接受的取舍 —— 换来的是**零依赖、零配置、零额外磁盘占用**。

需要长期存档请配合 CoreProtect。

**例外**：处罚记录（禁言 / 封禁）落盘到 `punishments.yml`。那不是日志，是状态 —— 重启之后禁言必须还在，否则换个时间再来就绕过去了。

| 项 | 环境 | 结果 |

| 控制台指令 | 两种版本 | 中英文子命令都识别，Tab 补全正常 |
| 并发 | 26.3 | SSE 挂着时 20 个并发请求全 200 |
| 世界操作 | 26.3 | 时间/天气/难度/规则/出生点/边界/清理全部实测，撤销可用 |
| 游戏规则兼容 | 26.3 | 14 条规则全部读到值（新旧命名都试过） |

**没测到的**（不谎报）：

- 「有新版本」的完整链路 —— 版本服务上没有真实发版记录，`has_update: true` 的分支只做了静态渲染验证
- CSV 公式注入的实际拦截 —— 手头日志里没有以 `=` `+` `-` `@` 开头的内容，触发不了

## 已知限制

- **操作日志只在内存里**，重启清空（处罚记录除外，见上）
- **不能跨服**（多子服要每个服各装一个，各自看各自的）
- **插件占用只能给可测指标**：内存按插件拆分做不到，别信任何号称能测的
- **计划任务的 `restart` 会直接关服**：配错时间就是线上事故，建议只在自己能盯的时候用
- **只记录插件装上之后的事**：装之前的方块改动查不到
